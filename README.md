# Movieticketsbooking
# 🎬 Dark-Ops Cinema: AI-Powered Movie Ticket Booking Platform

A full-stack, high-performance solo Java web application designed for comprehensive theatre management. This application features optimization algorithms and enterprise design patterns to maximize operational throughput and deliver an interactive user experience.

## 🚀 Key Innovation Metrics & Features

### 1. Smart & Dynamic Seating Infrastructure
* **Vibe-Based Seating Tags & Heatmaps:** Users select a social tag during interaction (`Quiet Watcher`, `Cheering/Excited Fan`, `Couples/Quiet Corner`, `Family with Kids`). The system reads database tag layers to compute and display a fluid visual seating preference heatmap.
* **Auto-Seat Allocation (Gap Minimizer Algorithm):** Implements a backend Java matrix optimization loop that instantly identifies optimal display viewport angles vs. screen distance while systematically eliminating single-isolated seating gaps for the venue operator.
* **Simulated Viewport POV Canvas:** Offers a live perspective rendering modal, mapping viewing strains dynamically based on chosen rows (Front, Middle, or Balcony).

### 2. Social & Financial Group Engineering
* **Group Split-Pay & Hold Engine:** Emplements a custom Java in-memory map cache simulating a strict 10-minute seat lock pipeline. It holds a selection cluster open while sending distributed individual validation routes to team members.
* **Mystery Box Movie Screening:** A randomized blind box protocol that obfuscates premium titles while highlighting targeted operational genres at highly discounted pricing tiers.

### 3. In-Theatre Operational Logistics
* **Precision Concession Timeline Mapping:** Allows patrons to schedule exact refreshment arrivals (e.g., *During Intermission*, *15-minutes Post-Start*).
* **Calorie & Combo Customizer Engine:** Utilizes the structural **Java Decorator Pattern** to enable infinitely combinable food calculations with fluid calorie tracking matrices and real-time total accounting updates.

## 🛠️ Technology Stack Architecture

* **Backend Architecture:** Native Standalone High-Performance Java HTTP Server
* **Language Dominance:** Pure Core Java Object-Oriented Pipelines (100% Max Native Utilization)
* **Database Management Layer:** Structured Local Embedded SQLite DB Engine (`movietickets.db`)
* **Data Connectivity Engine:** Java Database Connectivity (JDBC) Standard Driver Link
* **User Control Room Interface:** Modular HTML5 Canvas APIs, Responsive CSS3 Grid Configurations, and Vanilla JS asynchronous `fetch()` API streams.

## 💻 Local Setup & Execution Guide

The platform comes with zero-config compilation scripts built directly into the folder framework.

1. Launch your integrated terminal environment within the repository root folder.
2. Execute the automated environment launch profile:
   ```powershell
   .\run.ps1
   ```
3. Open your browser and navigate to the live operational server port:
   ```text
   http://localhost:8081
   ```
